# Zephyr Embedded Projects

Collection of **Zephyr RTOS-based embedded projects** on ESP32 and STM32, covering BLE, WiFi, MQTT, sensors, and real-time control.

---

## Projects

### BLE
- BLE Beacon  
- BLE Find Me  
- OTA BLE Smart Lock  
- Smart Access Control  

### Sensors & Communication
- I2C Scanner  
- I2C Temp + OLED (BME280 + SSD1306)  
- WiFi MQTT Sensor Node  

### Robotics & Control
- Ultrasonic Radar  
- Ultrasonic Radar (Interrupt)  
- WiFi Radar  

### Fundamentals
- Button Interrupt LED  
- LED Binary Pattern  

### Board Support
- STM32F303RE Setup  

---

